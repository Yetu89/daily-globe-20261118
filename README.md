THE DAILY GLOBE — one image that sums up the world's news of Wednesday 18 November 2026: 13 stories and 5 in-brief items across 6 continents, drawn as a single 1024×1024 newspaper front page. Lead: Trump lands in Manila as Asia's summit week opens. The image is drawn offline by `tools/build_image.py` from the checked stories in `tools/stories.json` and shipped as `entry.png`; `main.py` copies it to the output directory byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
